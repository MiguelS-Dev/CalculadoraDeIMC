🧩 Explicando o Desafio

Esse projeto foi criado como um desafio pessoal para praticar JavaScript, HTML e CSS construindo uma Calculadora de IMC (Índice de Massa Corporal). A ideia principal era desenvolver uma aplicação simples, mas funcional, que recebesse os dados de peso e altura do usuário, calculasse o IMC com base nesses valores e mostrasse o resultado de forma clara e estilizada.

O objetivo do desafio foi:

✔️ Entender a lógica de cálculo

O cálculo do IMC é feito dividindo o peso (em kg) pela altura ao quadrado (em metros), conforme a fórmula padrão usada em saúde para indicar se uma pessoa está dentro, abaixo ou acima do peso ideal.

✔️ Aplicar JavaScript para lógica dinâmica

Utilizei JavaScript para:

Capturar os valores digitados pelo usuário;
Calcular o IMC;
Exibir o resultado e sua classificação na interface;
Resetar os campos quando necessário.

Isso me ajudou a reforçar conceitos como manipulação de DOM, eventos e validação básica de inputs.

✔️ Construir uma interface simples e funcional

Com HTML e CSS, estruturei a interface de forma clara, com campos de entrada, botão de cálculo e área de resultado. A responsividade e a usabilidade foram pensadas para manter a aplicação intuitiva, mesmo sendo um projeto básico.

🎯 O que aprendi com esse projeto

Esse desafio foi uma ótima maneira de consolidar meus conhecimentos fundamentais de front-end, especialmente no uso de:

JavaScript para lógica e interação;
HTML semântico;
CSS para design e layout.

Apesar de simples, ele representa um passo importante na minha evolução como desenvolvedor, pois me forçou a integrar lógica de programação com interface de usuário real. 😊# CalculadoraDeIMC
